# 재난생존 게임 — MVP 스펙·구현 태스크 (검토용 초안)

2026.11.19 정리 · 슬랙 킥오프 스레드와 첨부 원문 9건 대조 · 기한·일정 약속 없음 · 이 문서는 누구에게도 연락하거나 배정을 통지하지 않음

## 확정 조건 (사용자 결정)

1. 목적: 모바일/웹에서 바로 돌려볼 플레이테스트용 프로토타입 (이후 스토어 출시 목표)
2. 플랫폼: 스마트폰 웹(HTML/JS) 우선
3. 수치 기준: 시안 이미지가 아니라 첨부된 Godot 시드 코드(턴당 6 AP) 기준으로 통일

역할 제안(Instinct 조율 / Claude 구현 / 피클1·피클2 조사)도 승인됐습니다. 다만 각자의 수락 확인은 스레드에서 별도로 이뤄져야 합니다.

## 자료 현황

- 확보 완료 9건: 기획 마스터 프롬프트, Godot 시드 스크립트 2종(tactical_grid_combat.gd, scavenge_noise_manager.gd), 컨셉 아트, 화면 시안 3점, 스프라이트 시트, threads-game-collection.md
- threads-game-collection.md는 사용자가 수집한 정리본입니다. 에셋 팩 3종의 스토어 링크와 "상업 이용 가능" 주장이 담겨 있지만, 이는 사용자가 모은 참고 정보이며 스토어 출시 작업 전 각 판매 페이지에서 직접 다시 확인해야 합니다. 플레이테스트용 프로토타입 참고에는 지장이 없습니다.
- 미확보: 에셋 팩 3종(Kharon Free Starter, PSX Aftermath Survival Items Sampler, Godot 4 Zombie Survival Starter Kit v1.3)의 원본 파일. 프로토타입은 임시 아트로 진행 가능합니다.

## MVP 범위 (정리 제안 — 사용자 확정 아님)

한 번의 출정: 임시 쉼터/출정 → 폐건물 탐사(방 2~3개 · 제안) → 소음 누적·매복 → 6×6 전투 → 승리·도주·패배 → 귀환 정산.

오픈월드·시설 확장·다중 생존자·주야 순환·복합 부상은 후속 단계로 미루는 안입니다.

## 탐사 규칙 (시드 코드 그대로)

수색 3방식:
- SILENT: 소음 6~10 / 고철 1~3·탄약 1~2
- FAST: 소음 25~35 / 고철 3~6·탄약 2~5·40% 통조림
- BREACH: 소음 40~50 / 고철 5~8·탄약 4~8·붕대 1

매복 트리거: 소음 75 이상 45%, 100 도달 시 확정(방사능 돌연변이 워커).

## 전투 규칙 (시드 코드 그대로)

6×6 그리드, 턴당 6 AP.
- 이동 1칸: 1 AP
- 속사: 2 AP — 명중 = clamp(0.95 − 거리×0.08 − 엄폐, 0.25, 0.95), 피해 16~26
- 조준사격: 4 AP — 항상 적중, 피해 38~55
- 응급처치: 3 AP — HP +35, 붕대 1 소모

엄폐(인접 엄폐물 기준 절반 0.25·완전 0.50)는 두 곳에 적용됩니다:
- 내 사격: 명중률에서 차감
- 적 근접 공격: 피해 ×(1 − 엄폐) 감쇄

방사능 타일 진입 시 HP −5. 플레이어 선공 고정, HP 100·탄약 12·붕대 2. 적(돌연변이 워커) HP 65~70, 매 턴 1칸 접근 후 근접 공격 14~24 × (1 − 엄폐). 승리 시 고철 4~8 획득.

## Claude 구현 태스크 (HTML/JS 포팅 기준)

- T1 · 프로토타입 골격: 쉼터·탐사·전투 3개 화면 상태와 전환. 완료: 스마트폰 브라우저에서 터치만으로 세 화면을 오갈 수 있음.
- T2 · 탐사 화면(scavenge_noise_manager.gd 포팅): 수색 3방식·소음 게이지·매복 트리거를 시드와 동일한 수치·확률로. 완료: 방식별 소음·보상이 시드 표와 일치, 75 이상 45%·100 확정 매복 재현.
- T3 · 전투 화면(tactical_grid_combat.gd 포팅): 6×6·6 AP·행동 4종·엄폐·방사능 타일·적 AI·승패 판정을 시드 수치로. 완료: AP 차감·명중 공식·엄폐 효과(사격 명중 차감·근접 피해 감쇄)가 시드와 일치.
- T4 · 출정 루프 연결: 매복→전투→귀환·정산, HP·탄약·소지품·수색 컨테이너 상태 보존. 완료: 아래 완료 판정 5개 통과.
- T5 · 임시 UI·아트 배치: 시안은 배치 참고로만. 완료: 화면 표시 수치가 모두 시드 코드 값.

## 완료 판정 (프로토타입이 갖출 것)

1. 출정 → 탐사 → 발각 → 전투 → 복귀/귀환 → 정산이 한 흐름으로 끝나고 패배·도주 결과도 정의됨
2. 빠른 수색과 조용한 수색의 시간·위험 차이가 실제 플레이에 나타남
3. AP가 정확히 차감되고 AP 부족·막힌 타일은 규칙과 UI에서 같이 거부됨
4. 전투 전환 전후로 상태가 보존됨
5. 스마트폰 웹 실기기에서 입력·글자·전투 그리드가 읽힘

## 시드에 없는 것 — 확인이 필요한 보완 규칙 (정리 제안)

- 조준사격 명중: 시드는 판정 없이 항상 적중(38~55). 기획 프롬프트의 "명중 +35%·치명타 +20%" 보정과 다르지만 정해진 기준에 따라 시드대로 구현하고 확인 항목으로 남김.
- 턴 순서: 시드는 플레이어 선공 고정. 프롬프트의 민첩 이니셔티브는 이번 범위에 넣지 않음.
- 탄약 0일 때 근접 기본 행동, 도주 조건과 비용, 패배 시 획득물 손실 규칙이 시드에 없음. 최소안을 채워 확인 필요.
- 매복 시 적 수와 전투 그리드 배치 규칙이 없음. 첫 프로토타입은 적 1명 고정으로 제안.
- 기획 프롬프트가 요구하지만 시드와 MVP 범위에 없는 것(골절·감염·방사능병, 무기 내구도·탄종 관통, 쉼터 시설 트리, 다중 생존자, 주야 순환, 격자 인벤토리)은 프로토타입 검증 뒤 후속 스펙으로 미룸. 쉼터 시안의 시설·생존자 관리 화면도 보류 범위.

## 담당별 작업 (승인된 역할 기준, 수락 확인 별도)

1. Instinct — 스펙 조율·자료 관리: 스펙 초안과 태스크 전달, 수치 변경 요청 집계, 에셋 팩 원본 확보 지원.
2. Claude (슬랙 @claude) — 구현: T1~T5 수행, 완료 판정 5개 통과.
3. 피클1·피클2 — 조사: 레퍼런스 게임 3종 코어 루프·조작 조사, 에셋 팩 3종 실파일 확보와 상업 이용 라이선스(판매 페이지에서 직접 확인)·HTML/JS 호환성 확인, 출시 체크리스트 초안. 프로토타입과 병행 가능.
4. 아트 — 담당 미정: 시안·스프라이트를 실제 리소스로 만들지는 프로토타입 검증 뒤 결정. 첫 검증은 임시 아트 허용.
